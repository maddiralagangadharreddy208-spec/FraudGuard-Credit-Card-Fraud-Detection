
# FraudGuard - Credit Card Fraud Detection

A machine learning application that detects potentially fraudulent credit card transactions using Python, Random Forest, and Streamlit.

## Features
- Machine learning-based fraud prediction
- Interactive Streamlit interface
- Data analysis and visualization
- Fraud classification using Random Forest

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Installation

1. Clone the repository:
   git clone https://github.com/maddir alagangadharreddy208-spec/FraudGuard-Credit-Card-Fraud-Detection.git

2. Open the project folder:
   cd FraudGuard-Credit-Card-Fraud-Detection

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   streamlit run app.py

## Project Purpose
This project demonstrates how machine learning can help identify potentially fraudulent credit card transactions.
